# Quick Start: Install Your Learning App

## Step 1: Generate Icons (2 minutes)

**Easiest Method:**
1. Open `icon-generator.html` in your browser
2. Customize your icon (change text, colors)
3. Click "Generate All Sizes"
4. Save all 8 downloaded files to the `icons/` folder

## Step 2: Deploy to GitHub Pages (1 minute)

```bash
git add .
git commit -m "Add PWA support with icons"
git push
```

## Step 3: Install Your App

### Your GitHub Pages URL:
**https://ashutoshnayakORDS.github.io/courses/**

### On Your Phone:

**Android:**
1. Open Chrome and visit the URL above
2. Tap menu (⋮) → "Install app"
3. Tap "Install" in the prompt
4. App appears on your home screen!

**iPhone:**
1. Open Safari and visit the URL above
2. Tap Share button (□↑)
3. Tap "Add to Home Screen"
4. Tap "Add"
5. App appears on your home screen!

### On Your Computer:

**Chrome/Edge:**
1. Visit the URL above
2. Click the install icon (⊕) in the address bar
3. Click "Install"
4. App opens in its own window!

## Step 4: Use Your App

- Open from home screen/desktop
- Works offline after first load
- Gets automatic updates when you push to GitHub
- No browser UI, feels like a native app!

## That's It!

Your course is now an installable app. Update course content by editing files and pushing to GitHub.
